# valoart

Valorant Chat Arts search + ASCII text generator, built with Astro + React.

## Features

- **Valorant Chat Arts searchbar** — search the chat arts gallery, filter by category, and copy an art.
- **Text ASCII Generator** — type text, get fixed-width block art for VALORANT chat, and copy it.

## Run locally

```sh
npm install
npm run dev
```

Then open http://localhost:4321/

## Build

```sh
npm run build
```
